# desktop/

Desktop app for **Windows and macOS** (Linux later): Kotlin, Compose Multiplatform, webrtc-java. Thin shell around `shared/` plus tray, incoming call window, hotkeys and installers (`packaging/windows`, `packaging/macos`, `packaging/linux`).

Design: [docs/06-platforms.md](../docs/06-platforms.md#2-desktop-windows--macos-desktop). Not implemented yet.
